# Homepage image slots

Place your image files in this folder with these exact names:

- `logo.png` - Chain Daan logo for the header
- `hero-map.png` - Ilocos Norte map and/or character artwork for the hero
- `mascot.png` - Chain Daan mascot overlay for the hero
- `delivery.png` - supplier delivery handoff artwork for the How It Works section
- `product-1.png` through `product-4.png` - images for the Popular Products cards

PNG, JPG, and WebP files are supported. Update the paths in `src/App.jsx` if you prefer different names.
